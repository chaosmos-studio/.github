# Security policy

## Reporting a problem

Please don't report security problems in a public issue, post or comment.
Write to [hello@chaosmos.studio](mailto:hello@chaosmos.studio) with "Security" in the subject.
Say what is affected, how to reproduce it, and what someone could do with it.
We reply within a week and keep you updated until it is fixed.

## What's covered

- Our games and apps, on Google Play and in the browser at chaosmos.studio.
- The chaosmos.studio website and the game sites under it.
- The repositories in this organisation.

Problems in Google Play, AdMob, GitHub or another service we use belong with that service.

## Supported versions

Only the latest release of each game gets security fixes.
Update it from Google Play, or reload the page for the browser version.

## Credit

If you'd like, we'll thank you by name in the release notes of the fix.
