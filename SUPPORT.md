# Getting help

- **With a game:** each game's support page has answers to common questions and a way to report a bug.
  - [Plumb](https://chaosmos.studio/games/plumb/support/)
  - [Carillon](https://chaosmos.studio/games/carillon/support/)
  - [Apsis](https://chaosmos.studio/games/apsis/support/)
- **Anything else:** write to [hello@chaosmos.studio](mailto:hello@chaosmos.studio).
- **With other players:** [r/chaosmos_studios](https://www.reddit.com/r/chaosmos_studios/).
- **Purchases and refunds:** every purchase goes through Google Play, so refunds follow [Google Play's refund policy](https://support.google.com/googleplay/answer/2479637).
- **Privacy:** each game's privacy policy is on its site, for example [Plumb's](https://chaosmos.studio/games/plumb/privacy/).
