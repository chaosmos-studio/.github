# .github

The Chaosmos organisation's profile and its default community health files.

- [profile/README.md](profile/README.md) is the page shown at [github.com/chaosmos-studio](https://github.com/chaosmos-studio).
- The other files are used by every repository in the organisation that doesn't have its own: [code of conduct](CODE_OF_CONDUCT.md), [contributing](CONTRIBUTING.md), [security policy](SECURITY.md), [support](SUPPORT.md), [governance](GOVERNANCE.md), the [sponsor button](FUNDING.yml), and the [issue](ISSUE_TEMPLATE/) and [pull request](PULL_REQUEST_TEMPLATE.md) templates.
